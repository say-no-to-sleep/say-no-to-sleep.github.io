# LCARS Color Guide 
The following are colors used in the various LCARS themes. Each color block includes the HTML HEX code and CSS custom property name. Some colors were modified for LCARS version 26 and may differ from previous versions. 
NOTE: The accordion drop-down feature on this page is currently being fine-tuned for LCARS version 26.1 and is not fully supported in the current version of LCARS.
