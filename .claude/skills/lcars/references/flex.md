# 2 Column Layout with Flex 
Creating a 2 column layout to divide your content on a page is easy with the flex property already baked into the template's CSS. And since this is a flex layout, the columns will wrap on smaller viewports. Column 2 will wrap underneath Column 1. Here is the HTML followed by the output: 
```

<div class="flexbox">
	<div class="col">
		<h2>Column 1</h2>
		<p>Lorem ipsum...</p>
	</div>
	<div class="col">
		<h2>Column 2</h2>
		<p>Lorem ipsum...</p>
	</div>
</div>
```
