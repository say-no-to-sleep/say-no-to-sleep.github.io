# An image that is centered  
Star Trek: The Next Generation 

## HTML 
```

<img src="tng.jpg" class="pics">
<p class="caption">Star Trek: The Next Generation</p>
```

No need to place the picture in a div here. Simply add the class "pics" to the `<img>` tag and you're good to go. Did you catch that the page heading (`<h1>`) is also centered? If you ever want to center text, just add the class name `go-center` to a text element.
