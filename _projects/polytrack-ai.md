An agent for the browser racing game PolyTrack. It trains on many randomly generated tracks so it has to learn driving techniques that carry over between tracks, instead of memorizing one, and then searches ahead in the simulator to find moves that plain reinforcement learning rarely discovers.

Work in progress. The plan and progress are in the logs below.
