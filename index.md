## About

Computer Engineering student at the University of Waterloo with experience in computer vision, machine learning, and embedded systems.

I am fascinated by computer architecture, machine learning and astrophysics, especially where some overlap: specialized hardware for ML, computer models for physical systems, and practical tools that make work easier.

## Skills

- **Languages:** Python, C, C++, Java, Swift, MATLAB, TypeScript, Bash
- **ML and vision:** OpenCV, Scikit-learn, YOLO, NumPy, SciPy, pandas
- **Embedded and systems:** STM32, Raspberry Pi, ROS 2, Linux real-time and networking, AWS and Azure
- **Coding theory and cryptography:** GF(2) linear algebra, Reed–Muller codes, cryptanalysis
- **Other:** SwiftUI, ARKit, Metal, orbital mechanics, Git
